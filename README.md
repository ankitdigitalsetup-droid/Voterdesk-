# VoterDesk Candidate Admin

Responsive UI/UX prototype prepared for localhost and Vercel.

## Run on localhost

1. Install Node.js LTS.
2. Open this folder in Terminal.
3. Run:

   ```bash
   npm install
   npm run dev
   ```

4. Open http://localhost:3000
5. On the login screen, keep the pre-filled demo details and click **Sign in securely**.

## Deploy on Vercel

Upload this project to a private GitHub repository, import the repository in Vercel, and click **Deploy**. Vercel should detect Next.js automatically.

## Prototype limitations

- Login is simulated and does not verify credentials.
- Excel upload/import is a visual workflow using demo data.
- Data is not connected to a database.
- Do not add real voter data until authentication, encryption, access controls, consent controls, audit logs, and a lawful data-processing policy are implemented.
